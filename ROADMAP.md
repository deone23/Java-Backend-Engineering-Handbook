# Completion Checklist

A module is considered complete only when all of the following are true.

- [ ] I understand the problem it solves.
- [ ] I can explain how it works internally.
- [ ] I can draw the execution flow.
- [ ] I can implement it without referring to notes.
- [ ] I can debug common issues.
- [ ] I can answer beginner interview questions.
- [ ] I can answer intermediate interview questions.
- [ ] I can answer senior scenario-based interview questions.
